## Current Work

### [High-Performance Order Matching Engine](https://github.com/Hunter-420)
A from-scratch order matching engine built for correctness and speed.

- Price-time priority matching with limit and market order support
- Fixed-width binary serialization for zero-copy message handling
- Memory arenas for deterministic, allocation-free hot paths
- Non-blocking I/O via Linux `epoll` with `TCP_NODELAY` to suppress Nagle's algorithm
- POSIX threads with explicit core affinity and lock minimization
- Profiled with `perf` and traced with `strace` to identify and eliminate bottlenecks
